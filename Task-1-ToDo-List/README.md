## Task 1: To-Do List Application

### Project Description

This project is a simple To-Do List Application developed using Python. It helps users manage their daily tasks through a simple menu-driven interface.

### Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Simple command-line interface

### Technologies Used

- Python 3
- VS Code

### How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python todo.py
```
